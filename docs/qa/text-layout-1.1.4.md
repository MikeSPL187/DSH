# Обрезания текста и статус рассуждения — 08.11.2026

Исходные примеры: пользовательские снимки 2190/2191, DSH 1.1.4. Изменение не затрагивает палитру, шрифты и иконки.

| Проблема | Причина | Изменение |
|---|---|---|
| Баланс/сегодня/за месяц с многоточием | Три фиксированные колонки и maxLines=1, независимо от длины суммы и font scale | Ширина значений и подписей измеряется с текущим шрифтом. Короткие значения сохраняют три колонки; длинные переходят в строки на всю ширину карточки, с переносом полного значения и валюты. |
| Обрезано название модели в Настройках | Значение справа ограничено 46% ширины и одной строкой | Полная модель показана под заголовком строки, с переносами. Остальные строки настроек сохраняют прежнее расположение. |
| В чате видна только часть режима доступа | Горизонтальная лента чипов с fade справа; длинная модель также ограничена одной строкой | Чипы переносятся на следующие строки, длинное название переносится внутри чипа; кнопки сохраняют нажатие. |
| «Готово» во время рассуждения/работы | Любой текст ассистента закрывал ход даже при активном запросе | Активный запрос остаётся Running при reasoning-only, промежуточном тексте и частичном ответе. Завершённый запрос по-прежнему закрывается, даже если старый tool status запаздывает. |

Проверка логики: ChatLogicTest — reasoning-only после завершённого инструмента, промежуточный текст, частичный ответ, переход активный → завершённый и запоздалый tool status.

Нативная проверка: ChatTextLayoutTest использует настоящие производственные компоненты StatRow/StRow/ChatComposer и экран ModernChatScreen. На ширинах 320/360 dp и font scale 1.0/1.3 проверяются реальные границы строк TextLayoutResult и сохранение всех символов, отсутствие ellipsis, границы viewport, нажатие режима доступа и переход «рассуждает → готово». Снимки сохраняются в Android device QA artifact. Это проверка контролируемого UI-состояния; живой запрос DeepSeek здесь не выполняется.
