## Совместимость и интерфейсы

Room и формат backup не меняются. Состояния подготовки экспорта находятся в памяти процесса; они переживают Activity recreation, но после смерти процесса экспорт можно запустить заново. Новый scheduler хранит только отметки постановки и времени запуска в отдельных SharedPreferences. Поля модели автоматизации, добавленные в раунде 2, используются без новой миграции JSON.

Внутренние интерфейсы UI расширены состоянием подготовки экспорта и методом получения состояния расписания. Публичный plugin SDK и протокол Host не меняются. Исходные чаты, проекты, ключи и выбранные права не удаляются.

## Проверки

Целевой прогон: Round3BehaviorTest, Automation*, AppLanguageLegacyTest, QaRegressionUiTest. Проверяются транспорт Wi-Fi, маркеры повторов, Stockholm DST, модель/провайдер, возврат из Plugins, однократная доставка экспорта и чтение ZIP получателем, ввод ключа через IME и доступные имена Settings. Сохраняются проверки F004, темы без Host и восстановления Appearance из раунда 2.

Полный CI и сборка проверяются на конкретной ревизии; результаты, APK, SHA-256 и нативные доказательства сохраняются отдельно с итоговыми статусами. Не считать написанный тест или исходный отчёт доказательством прохождения нового APK.

## Оставшийся интеграционный проход

На API 30: нативная клавиатура + Continue/Skip/Show, возврат Settings→Plugins→Back, RU/EN, экспорт в обеих локалях и получение ZIP другим приложением. Для настоящего Host: PTY, MCP, usage и автоматическое выполнение задания после зарядки/Wi-Fi без Run now. Нужны также API 33+ для platform locale и физическое устройство для performance/TalkBack. До этих проверок PR остаётся draft; ограничения окружения фиксируются в итоговом отчёте.

Источник для моста TextFieldValue: официальный sources JAR Compose Foundation 1.7.8, `commonMain/.../BasicTextField.kt`: https://dl.google.com/dl/android/maven2/androidx/compose/foundation/foundation/1.7.8/foundation-1.7.8-sources.jar . Тест пакетного ввода проверяет несколько вставок до recomposition, замену выделения и внешнюю замену текста.
