# N19: плавность пока не подтверждена

Исходные измерения: [Android device QA 42222690339](https://github.com/MikeSPL187/DSH/actions/runs/42222690339), source `501dcdbb`. Debug APK, KVM, один AVD 3072 МБ / 3 ядра, SwiftShader. Метрики сняты после функционального обхода с uiautomator, сменой тем и поворотами. Это не изолированный benchmark прокрутки чата и не измерение итогового release APK.

| API | TOTAL PSS, КиБ | Кадры | Jank | Legacy jank | p50 / p90 |
|---|---:|---:|---:|---:|---|
| 30 | 154577 | 1863 | 89.86% | — | 23 / 34 мс |
| 33 | 162136 | 2257 | 25.92% | 80.73% | 27 / 42 мс |
| 35 | 167065 | 3516 | 17.63% | 82.79% | 29 / 46 мс |

Разные Android по-разному классифицируют jank, поэтому проценты между API не сравниваются напрямую. Поздние функциональные прогоны снимают gfxinfo после force-stop: несколько кадров последнего запуска не характеризуют прокрутку. Пустой crash buffer также не доказывает плавность.

Для приёмки N19 нужен следующий отдельный проход:

1. На одном физическом устройстве и одной версии Android сравнить публичный release 1.1.3 и подписанный release 1.1.4. Зафиксировать модель, частоту экрана, масштаб шрифта, питание/температуру и состояние энергосбережения. На обеих версиях использовать одинаковую локальную сессию и длину сообщений.
2. Дождаться прогрева Host и загрузки истории. Сбросить gfxinfo перед измерением, затем повторить одинаковую прокрутку длинного чата и открытие клавиатуры. Отдельно измерить streaming; сетевые задержки не смешивать с локальной прокруткой.
3. Сделать несколько повторов каждого сценария, сохранить framestats и трассу Perfetto. Сравнить медиану/p90/p99 длительности кадров и долю кадров сверх бюджета той же частоты экрана. Не включать установки, переключение языков и force-stop в этот интервал.
4. Если задержка воспроизводится, определить по трассе участок main thread/render thread, внести адресное исправление и повторить тот же сценарий. Только после сопоставимого результата менять статус N19.

Физическое устройство в этой среде недоступно. Из этих данных нельзя заключить, что N19 исправлен или что конкретная оптимизация устранит исходный дефект.
