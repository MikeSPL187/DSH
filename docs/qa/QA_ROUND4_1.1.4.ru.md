# QA раунд 4 — кандидат DSH 1.1.4 (114)

Проверенный QA merge-коммит `28d67460e25d6ecc002dda1c81078503e087b458` содержит `d1ad335d` поверх опубликованной 1.1.3. Это регрессия кандидата PR №2. Приложен текст отчёта; его исходные screenshots, JSON и logcat в этой среде отсутствуют. Статическое подтверждение причины и прохождение написанного теста не заменяют нативное воспроизведение.

## Совместимость и доставка

Версия APK остаётся 1.1.4 / 114, PR №2 — draft. Формат backup и Room не меняются. RuntimeStatus получает необязательный stopReason, HostRuntimeManager — перегрузку stop(reason) с совместимым методом по умолчанию. AutomationActions.save сообщает успех, чтобы редактор не закрывался после отказа. Новые ошибки Host имеют стабильный код `dsh/auth/expired`; повтор prompt остаётся явным действием пользователя. HostRequestException сохраняет код ошибки в Result API, чтобы фильтр текста не превращал сообщение об авторизации в сетевую ошибку.

Исправление passwd/group применяется APK к уже установленному rootfs при следующем запуске. curl и Android subprocess owner требуют нового rootfs; простой APK со старым rootfs-v2.0.0 их не доставляет. CI собирает кандидаты x86_64/arm64; опубликованный манифест APK не переключается на отсутствующие release assets. Публикация rootfs, смена SHA-256/URL в манифесте и проверка полного обновления — отдельный финальный шаг после подготовки образов. Не выдавать APK-only проверку за прохождение нового образа.

Android owner даёт отмену наблюдаемых потомков с защитой от повторного использования PID. Это не kernel containment: быстро отделившийся потомок между сканированиями может остаться ненаблюдаемым. На Android этот предел проверяется отдельно; чужие процессы не завершаются ради очистки.

## Проверки

Продолжение проверки выявило дефект упаковки: в кандидате `d83f95f3` заменялся только CLI (`replaced 1`), а hoisted `@deepseek-ai/*` оставались из npm. Старый `find node_modules -path '*/node_modules/…'` не совпадал с корневыми зависимостями. Этот кандидат нельзя использовать для подтверждения исправлений агента. Обход теперь обрабатывает все уровни node_modules; контрольные суммы source overlay проверяются после npm prune и включаются в SBOM. Регрессия проверяет hoisted/nested пакеты, сохранение lockfile metadata и обнаружение подмены опубликованным кодом. CI дополнительно устанавливает и удаляет Debian-пакет с postinst через PRoot на обеих архитектурах.

Добавлены Compose-проверки замены ключа через Done/Save и ожидания проверки, а также отдельный instrumentation-тест с настоящей IME и касанием Save по экранным координатам; наследования/неоднозначности модели; сохранения выключенного Terminal; возврата в приложение до отложенного stop; сохранения Debian accounts; обновления Host cookie без второго prompt; Android process identity, TERM/KILL и освобождения TCP-порта. Итоги каждого фактического прогона и ссылки CI фиксируются в артефактах с точной ревизией.

Нативный проход: API 30 и 33+, Replace key/Continue/Show, RU↔EN и rotation во время запроса, Settings/Plugins, реальное наступление времени при Wi-Fi/зарядке, offline→online, dpkg и установка пакета в proot. Gradle и эмулятор работают раздельно. Физическая производительность не оценивается по SwiftShader. Реальный ключ в логи, screenshots полей и XML не записывается.
