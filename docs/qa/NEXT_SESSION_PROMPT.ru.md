**Что делать дальше (задача владельца — проверить каждый экран в эмуляторе по 3 раза, исправить всё найденное, только потом переходить к следующему экрану):**
1. Подними эмулятор и Host:
   - `scripts/cloud/emulator.sh` (TCG, AVD `dsh26`, Android 8 / SDK 26). Без KVM загрузка занимает около 3 минут.
   - Прокси: `adb shell settings put global http_proxy 10.0.2.2:<порт из $HTTPS_PROXY>`. Порт свой в каждом контейнере.
   - Сборка: `bash scripts/cloud/gradle.sh :app:assembleDebug -q`, при работающем эмуляторе с `-Dorg.gradle.workers.max=1`. Полную проверку запускай только при остановленном эмуляторе, иначе не хватит памяти.
   - Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk` (на TCG занимает до 10 минут).
   - Linux (proot) на этом эмуляторе не работает, поэтому Host запускается в контейнере: `python3 scripts/cloud/external-host.py --rootfs <распакованный rootfs>` (подробности в начале скрипта; нужен `adb root`). Rootfs нужно скачать заново или достать из APK и ресурсов, прошлый контейнер был в scratchpad. Ключа DeepSeek в репозитории нет и не должно быть: попроси владельца ввести его в приложении сам. Ключ никогда не выводи и не коммить.
   - Не используй `pkill -f external-host.py`: команда убивает собственную оболочку. Ищи PID через `pgrep` и завершай по нему.
   - Окна «Интерфейс системы не отвечает» вызваны медленным эмулятором, а не DSH: нажимай «Подождать». Дамп uiautomator часто устаревший, сверяйся со скриншотом (`adb exec-out screencap -p`).
2. Первым делом проверь F021: приветственный экран → «Русский» → English → русский → «Начать» должна нажиматься. Проверь фокус: `dumpsys window windows | grep mCurrentFocus` не должен показывать «Pop-Up Window EXITING». То же проверь в Настройках → Язык.
3. Пройди круг по каждому экрану. После каждого исправления пересобери приложение и пройди экран заново.
   - Первый запуск:
     - ключ (маска и кнопка «Показать»);
     - папка;
     - установка и шаг «Запуск агента»;
     - сбой: «Агент не запустился» и кнопка «Открыть без агента».
   - Живой чат:
     - отправка сообщения;
     - выход из чата и возврат: не должно быть «ошибки сессии» (исходный баг владельца);
     - инструменты, остановка, markdown, 👍/👎.
   - Файлы: пустой файл («Файл пуст»), diff без «+0».
   - Плагины (имена), терминал.
   - Настройки:
     - тема;
     - режимы доступа, честные тексты;
     - расходы, хранилище;
     - MCP: секреты замаскированы, armed → «Отмена»;
     - язык.
   - Автоматизация и экран подтверждения опасного действия.
   - Обе темы, сверка с `docs/design/dsh-prototype.html`.
4. В конце обнови `docs/design/HANDOFF.md`, закоммить и запушь. Отчитайся владельцу по-русски, отдельно назови пункты QA, которые не исправлялись:
