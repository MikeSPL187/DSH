# Скачивание файла на телефон — 08.11.2026

В меню действий файла добавлен пункт «Скачать» / Download с существующей контурной иконкой DSH. Он расположен перед «Поделиться»; для папок не показывается.

1. Открыть «Файлы» → меню нужного файла → «Скачать».
2. В системном диалоге выбрать «Загрузки» или другое место. Предлагается исходное имя и соответствующий MIME-тип; имя можно изменить в диалоге.
3. Подтвердить сохранение. После окончания копирования приложение сообщает об успехе или ошибке. Отмена диалога не меняет файлы.

Файл копируется потоком в двоичном режиме, без перекодирования и без загрузки всего файла в память. Пустые файлы поддерживаются. Исходник сохраняется. Системный Storage Access Framework доступен с Android 8 и не требует нового разрешения на всю память. Выбранный источник хранится в saved state; копирование выполняется в applicationScope на IO и не отменяется при пересоздании экрана.

Перед запуском диалога и перед чтением проверяется обычный файл внутри рабочей папки. Символические ссылки за её пределы, приватные файлы приложения и каталоги отклоняются. Получатель — content URI системного выбора документа. Источник открывается до назначения: исчезнувший файл не приводит к очистке назначения.

Проверки: WorkspaceFileDownloadTest (Robolectric API 26/34) — исходное имя/регистр расширения/MIME fallback; точное копирование двоичного файла 2 МиБ + 17 байт; пустой файл; отказ доступа; сохранение источника; отклонение недопустимых путей и file URI. QaRegressionUiTest — нажатие «Скачать» передаёт выбранный файл; у каталога пункта нет. Это тесты Android API под Robolectric; системный picker на физическом устройстве в этом проходе не проверялся.
