## Совместимость и данные

Room-схема не изменена, существующие чаты/ключи/проекты не удаляются. Новый журнал — отдельный приватный JSON с fsync и атомарной заменой; модель автоматизации расширена необязательными полями. Старый журнал разницы баланса больше не используется. Новый policy-модуль доставляется APK-патчем ревизии 41; rootfs/bridge manifests и их контрольные суммы не подменены.

Новая запись журнала не содержит API-ключи или MCP-токены. Она содержит текст запроса, путь вложения и частичный ответ на том же уровне приватного хранения, что кэш чата. Успешный запрос удаляется из журнала, неуспешный остаётся для явного повтора.

## Проверки сборки

Итоговые команды, числа тестов, APK и контрольные суммы фиксируются в сопроводительном `validation.txt` рядом с артефактами. Снимки Robolectric показывают реальный Compose UI, но не заменяют Android UIAutomator, IME, системные панели и proot/PTY.

Для независимого повтора:

```sh
node scripts/tests/android-consent-policy.test.mjs
./gradlew :core:model:test :core:protocol:test :core:data:testDebugUnitTest \
  :feature:settings:testDebugUnitTest :feature:chat:testDebugUnitTest :runtime:host:testDebugUnitTest
./gradlew :app:testDebugUnitTest --tests 'com.dsh.ChatSenderQueueTest' \
  --tests 'com.dsh.ChatRunJournalTest' --tests 'com.dsh.McpStateTest' \
  --tests 'com.dsh.ToolApprovalPolicyTest' --tests 'com.dsh.Automation*' \
  --tests 'com.dsh.HostStartup*' --tests 'com.dsh.ui.QaRegressionUiTest' \
  --tests 'com.dsh.AppLanguageLegacyTest' --tests 'com.dsh.ui.TerminalPasteTest' \
  --tests 'com.dsh.terminal.TermEngineTest'
./gradlew :app:assembleDebug :app:assembleRelease
```

Release-подпись владельца требуется для обновления установленного `app.dsh.mobile`; debug APK имеет отдельный пакет `app.dsh.mobile.debug` и ставится рядом. Не заменять владельческий keystore случайной подписью.

## Оставшийся интеграционный проход

1. API 30: ввести фиктивный секрет во все формы, включить Show, проверить UIAutomator dump без печати значения; проверить ввод/фокус и TalkBack.
2. Установленный Linux: загрузить новый deployment policy; создать/прочитать/удалить файл, отменить и подтвердить удаление; убедиться, что без разрешения файл остаётся. Запустить read-only автоматизацию без sandbox: немедленная ошибка, история не «Running».
3. Force-stop во время ответа, холодный запуск, частичный текст и Retry; отдельный тест, когда удалённый Host продолжает работу. Три быстрые отправки и сетевой обрыв без дубликатов.
4. HTTP и stdio MCP: Add→Restart→Running/Error, Stop/Start, Delete; секрет не виден в деталях и старом реестре.
5. Open terminal: включение bundle, shell, Ctrl+C, reconnect и вывод в чате. Установка Linux/backup SAF и возврат из DocumentsUI.
6. RU/EN, System/Porcelain/Graphite, фон/возврат, ротация, IME, font scale 1.3; status/navigation bars на API 30/35.
7. Реальный provider usage и баланс, повтор истории без двойного счёта; стоимость только после добавления проверенного тарифа.
8. Физическое устройство: cold start, PSS, FrameTimeline/jank. Метрики SwiftShader отдельно.
