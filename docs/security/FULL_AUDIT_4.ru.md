## 3. Гипотезы (путь до вреда не подтверждён — сначала проверить)

- **H-1.** `android_clipboard_set` от плагина Host пишет в буфер молча — подмена скопированного адреса/команды.
- **H-2.** Ответ на одобрение при сбое сети (`HostEventsClient.answerForwardedEvent`): ошибка HTTP глотается, событие уже помечено отвеченным — `next` по тайм-ауту не уйдёт; нужен исходник Host, есть ли у него свой срок.
- **H-3.** Терминал: каждый кусок вывода заново строит текст всего блока (до 3000 строк) — рывки на `npm install`; число блоков и моделей вкладок (`TerminalHub`) не ограничено за время жизни процесса.
- **H-4.** Лист деталей инструмента (`ToolDetailBody`) показывает аргументы и вывод одним `Text` без предела — если Host не обрезает вывод, многомегабайтный результат подвесит интерфейс.
- **H-5.** `ProcessOutputParser`: в фазе STARTING любая строка stdout Host с адресом и токеном (в т. ч. вывод npm-плагина) переназначает порт/токен клиента.
- **H-6.** Режим инструмента ищется по точному имени: инструменты MCP с префиксом/другим регистром могут не попадать под «Выкл.».
- **H-7.** Автоматизация в фоне без открытого интерфейса: `approvalPolicy` ставится из `LaunchedEffect` экрана — без UI режимы «Сразу/Выкл.» не действуют, запросы висят 10 минут.
