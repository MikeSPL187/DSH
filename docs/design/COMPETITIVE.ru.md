# DSH против официального DeepSeek Harness, Claude Code, Codex и OpenCode

Цель владельца: DSH — лучшее приложение для общения и программирования среди всех ИИ-приложений.
Здесь — что у конкурентов есть, что уже есть у нас, и что делать дальше. Обновлять при каждой новой функции.

## Только у DSH (мобильные преимущества)

Linux на телефоне без компьютера; вход по отпечатку; уведомления об одобрениях; голосовой ввод; автоматизации
по расписанию при закрытом приложении; резервная копия; ключи в Android Keystore; сеть агента по списку.

## Чего не хватает (по ценности для «общения и программирования» на телефоне)

1. **Откат правок к точке разговора** (checkpoints в Claude Code, undo в OpenCode). Сейчас — только откат файла
   через git. Нужна поддержка в Host: снимок рабочей папки перед ходом и «Вернуть файлы к этому сообщению».
2. **Инструкции проекта** (`AGENTS.md` — аналог `CLAUDE.md`/`/memory`): Host читает, редактора в приложении нет.
   Экран «Инструкции» в проекте: открыть, создать из шаблона, правка с предпросмотром.
3. **MCP-серверы** (`/mcp` в Claude Code): сейчас — общая форма настроек плагина. Отдельный экран: список, статус,
   добавить (команда или URL), выключить, инструменты сервера.
4. **Расход и контекст**: сколько токенов и денег ушло на сессию, заполненность контекста, «Сжать» заранее.
5. **Git до конца**: коммит и пуш из «Изменений» (сообщение уже пишет ИИ), ветка, создание PR (Codex).
6. **Несколько вариантов ответа** (best-of-N в Codex): запустить задачу 2–3 раза и выбрать лучший diff.
7. ~~Настройки веб-поиска и пределы агента~~ — готово; сверх официального — выключатель передачи вопроса поисковику.
8. **Поделиться сессией** ссылкой/файлом (OpenCode share) — экспорт есть, оформить как «Поделиться».
