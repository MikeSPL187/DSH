# DSH против официального DeepSeek Harness, Claude Code, Codex и OpenCode

Цель владельца: DSH — лучшее приложение для общения и программирования среди всех ИИ-приложений.
Здесь — что у конкурентов есть, что уже есть у нас, и что делать дальше. Обновлять при каждой новой функции.

## Уже есть у DSH (паритет или лучше)

| Возможность | Официальный DSH (Web) | Claude Code / Codex / OpenCode | DSH (телефон) |
|---|---|---|---|
| Ссылки «@файл»/«@сессия» | есть | `@file` есть | есть; в новом чате — файлы с устройства без Host |
| Цель сессии | GoalBar | — | панель цели: пауза, правка, готово, убрать вторым касанием |
| Проверка плана | вкладка плана | plan mode (Claude Code) | экран плана с замечаниями, карточка «Проверить» |
| Субагенты | дерево в шапке | subagents / Task | «Агенты» в доке, продолжение и «Стоп» |
| Маскировка секретов | только в отправленном | — | в отправленном + предупреждение до отправки с «Убрать» |
| Превью документов | Markdown, PDF, HTML, таблицы | — | Markdown, HTML без JS, PDF со сведением пальцев |
| Браузер для dev-сервера | iframe / webview | — | localhost, HTML рабочей папки, ссылки из терминала |
| Одобрение опасных действий | есть | есть | экран с размерами, свободным местом и «вернуть нельзя» |
| Ответвление сессии (fork) | есть | `/rewind` (Claude Code) — только разговор | есть |
| Терминал | панель | сам CLI | блоки с кодом выхода, «Объяснить», ссылки |
| Веб-поиск (Search API, результаты, приватность вопроса) | страница настроек | — | группа «Веб-поиск»; вопрос можно не передавать |
| Инструкции проекта (`AGENTS.md`) | — | `/memory` (Claude Code) | редактор общих, проектных и личных с бюджетом |
| Контекст и расход | кольцо у поля ввода | `/context`, `/cost` (Claude Code) | кольцо в шапке, состав, кэш, трата за день, «Сжать сейчас» |
| Пределы агента (таймаут, вывод, субагенты, параллельность) | карточки в «Плагинах» | файлы конфигурации | «Агент → Пределы агента»: степпер, «изменено», «Сбросить» |

## Только у DSH (мобильные преимущества)

Linux на телефоне без компьютера; вход по отпечатку; уведомления об одобрениях; голосовой ввод; автоматизации
по расписанию при закрытом приложении; резервная копия; ключи в Android Keystore; сеть агента по списку.

## Чего не хватает (по ценности для «общения и программирования» на телефоне)

1. ~~Откат правок к точке разговора~~ — готово: точки возврата файлов перед каждым сообщением (в приложении, без
   правок Host), «Вернуть файлы», «Вернуть файлы и разговор», «Только разговор», отмена возврата.
2. ~~Инструкции проекта~~ — готово: общие, проекта и личные, шаблон, «Правка | Вид», бюджет 64 КБ.
3. ~~MCP-серверы~~ — готово: список с состоянием, добавить по адресу (с токеном в хранилище Host) или командой,
   удалить, перезапуск Host. Список инструментов сервера — когда Host отдаст его клиенту.
4. ~~Расход и контекст~~ — готово: кольцо в шапке, лист с составом, расходом, тратой за день и «Сжать сейчас».
5. ~~Git до конца~~ — готово: коммит, вход в GitHub, отправка, новая ветка и запрос на слияние с описанием от ИИ.
6. **Несколько вариантов ответа** (best-of-N в Codex): запустить задачу 2–3 раза и выбрать лучший diff.
7. ~~Настройки веб-поиска и пределы агента~~ — готово; сверх официального — выключатель передачи вопроса поисковику.
8. ~~Поделиться сессией~~ — готово: Markdown текстом или файлом, секреты скрыты, шаги агента по желанию. Публичной ссылки (как OpenCode share) нет — нужен свой сервер.
