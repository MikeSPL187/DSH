# DSH Mobile 1.0.6 — исправления по аудиту: технический план и отчёт

Ветка: `claude/mobile-app-security-audit-8aocub`. Базовая версия: исходники тега
`app-v1.0.6` (upstream-коммит `72c35d2`, 834 файла, коммит `857d9a2` в этой ветке).
Загруженный APK сверен: SHA-256 `d97476013f80…e016588b3` совпадает с проверенным в аудите релизом.

## 1. Как проверялось

- Установлены Android SDK 35 и JDK 21, проект собирается целиком (`:app:assembleDebug`)
  вместе с Native UI SDK (composite build).
- Итоговый прогон `./gradlew test` + `:app:assembleDebug` + `:app:assembleRelease` (R8) + `:app:lintDebug`
  со строгой проверкой SHA-256 зависимостей: **349 прогонов тестов (202 в debug и JVM-модулях,
  147 в release-варианте), 0 падений; lint без ошибок.**
  До исправлений в релизе 1.0.6 один тест падал (`SlotCoverageTest`): CI собирал APK, но тесты не запускал.
- Добавлено около 30 тестовых классов. Они воспроизводят сценарии из аудита и найденные дефекты:
  неверный semver, `../` в имени пакета, откат обновления, zip/tar-ссылки, подмена дайджеста,
  DoS моста, сопряжение без токена, неверный TLS-отпечаток, миграция Room 2→3 на настоящем SQLite,
  переподключение WebSocket (MockWebServer), цикл пересоздания Activity под Android 8.1,
  уменьшение изображений, запрет буфера обмена, ELF-защита нативных библиотек и другие.
  Тесты на исправленные дефекты проверялись и на старом коде: там они падают.
- **Прогон на эмуляторе Android 8.0 (API 26, x86_64, русская локаль).** Пройдены онбординг, чат,
  отправка без Host, выбор модели и режима, боковое меню, правая панель (файлы, предпросмотр,
  терминал, браузер), магазин плагинов с реальной загрузкой и установкой APK, диалог доверия
  native-плагина (TOFU), все разделы настроек, смена языка, удалённое подключение, выход и
  перезапуск, поворот экрана, приватная рабочая папка, резервная копия. Падения ловились через
  `logcat -b crash`, зависания через дампы потоков.
- **Релизная сборка с R8**, подписанная тестовым ключом, тоже прогнана на эмуляторе: онбординг,
  настройки, приватная папка и загрузка нативного плагина из магазина (его dex отображён в процесс,
  имена SDK сохранены).
- **Ограничение стенда.** В облачной VM нет KVM, эмулятор работает в режиме TCG. Под ним PRoot
  падает (`IS_IN_SYSENTER(tracee)` — ограничение ptrace в QEMU TCG, не дефект приложения), поэтому
  функции, которым нужен работающий Host (ответы агента, сессии, автоматизация), на эмуляторе
  не проверены. Они покрыты unit-тестами и требуют реального телефона.

## 3. Статус по каждой находке аудита

### P0 — блокирующие

| ID | Что было | Что сделано |
|---|---|---|
| **N-01** | `discovery.scan(pinnedFingerprints = emptyMap())`: проверка подписи фактически отключена | Новый `NativePluginTrustStore`: pluginId привязывается к паре (packageName, SHA-256 сертификата), которую **явно одобрил пользователь**. Впервые найденный плагин получает статус `UNTRUSTED` и не загружается. Другой пакет или подписант с тем же pluginId получает `SIGNATURE_MISMATCH` и тоже требует повторного одобрения. APK с несколькими подписантами отклоняются. |
| **N-02** | Код companion-APK загружался в процесс приложения автоматически | Загрузчик вызывается только для `READY`, то есть одобренных плагинов. Перед загрузкой подпись перечитывается из системы (закрыто окно TOCTOU между сканированием и загрузкой). Отдельный sandbox-процесс не реализован: это архитектурное изменение SDK-контракта. |
| **N-03** | JS-пакет из манифеста APK ставился автоматически при каждом пересканировании | Автоустановка удалена. JS-пакет ставится один раз, в момент одобрения, и его источник показан в диалоге. |

В диалоге одобрения видны pluginId, имя пакета, полный отпечаток сертификата и связанный JS-пакет.
Там же предупреждение, что плагин получает все права приложения. Для изменившейся подписи
показывается отдельное предупреждение.

## 4а. Повторный аудит после переноса дизайна (код, добавленный и изменённый при редизайне)

Проверено заново: загрузка кода нативных плагинов, WebView и JS-мост, мост и Host (порты, токены),
хранение и показ секретов, распаковка архивов, пути и FileProvider, сеть, интенты, автоматизации.
Без замечаний: доверие к нативным плагинам (TOFU + повторная проверка подписи), мост (127.0.0.1,
токен 256 бит, сравнение за постоянное время), хранилище ключа (AES-GCM в Keystore, видны 4 символа),

## 5. Что остаётся и рекомендации

Все находки аудита (F-, N-, A-) и все найденные в ходе работы дефекты (D-01…D-49) исправлены,
кроме перечисленного ниже. Здесь — что именно не сделано и почему.

1. **N-02 — изоляция нативных плагинов в отдельном процессе.** Не сделано. Плагины рисуют свой
   Compose-интерфейс прямо в окне DSH, а вынос в отдельный процесс означает новый SDK-контракт
   (удалённый UI через IPC) и переделку всех существующих плагинов. Это архитектурное решение
   для авторов SDK. Сейчас риск закрыт другими мерами: явное согласие пользователя (TOFU) на
   пару «пакет + сертификат», повторная проверка подписи перед загрузкой, отказ при смене подписи.
2. **F-13 — полная декомпозиция `MainAppHost`/`ChatScreen`.** Сделана частично (см. таблицу).
   Полное разбиение логично совместить с запланированным редизайном интерфейса.
3. **F-16 — матрица совместимости «APK × rootfs × bridge».** Нужен работающий Host, то есть
   реальный телефон: на эмуляторе без KVM PRoot не запускается.
4. **Проверить на реальном телефоне** то, что на эмуляторе без KVM проверить нельзя: ответы
   агента и поток ответа, переподключение после смены сети, авто-сон, удержание Host в фоне
   с WakeLock во время задачи, уведомления о завершении, ошибке и ожидании одобрения
   (Android 13+), запрос одобрения в фоне. Логика этих функций покрыта тестами.
5. **После повторного аудита (E-01…E-18) проверить на реальном телефоне:** смену прав в чате
   (маршрут `/api/session/selectPermission` — как у остальных вызовов Host; если Host ответит ошибкой,
   приложение теперь сообщит «Не удалось сменить права»), запуск автоматизации с правами «только читать»,
   запуск Host из папки с пробелом или кавычкой в имени, вход по отпечатку на Android 11+.
6. **Поведенческие изменения, о которых стоит знать:**
   - удалённый Host и источники маркетплейса — только HTTPS (или `http://127.0.0.1` через SSH-туннель);
   - companion-плагины загружаются только после явного одобрения;
   - чтение буфера обмена агентом по умолчанию выключено;
   - запрос одобрения без ответа в течение 10 минут отклоняется;
   - доступ ко всем файлам можно не давать — тогда рабочая папка приватная;
   - резервная копия и диагностика отдаются через «Поделиться», а не лежат во внутренней памяти.
7. **Для релиза:** CI собирает release с R8 и проверкой SHA-256 зависимостей. При обновлении
   библиотек нужно перегенерировать `gradle/verification-metadata.xml` командой
   `./gradlew --write-verification-metadata sha256 test :app:assembleDebug :app:assembleRelease`
   и просмотреть изменения.
8. Русская локализация добавлена (интерфейс, сообщения среды и установщиков); язык выбирается
   в «Настройки → Общие» и работает на всех версиях Android, начиная с 8.
