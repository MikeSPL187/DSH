# DSH — агент DeepSeek Harness на телефоне

**Русский** · [English](README.en.md)

DSH — Android-приложение, которое запускает полноценный агент DeepSeek Harness прямо на
телефоне: настоящий Host, инструменты, терминал и плагины работают локально, без компьютера.
Это самостоятельная ветка развития проекта. Наш фокус — **безопасность, надёжность и
интерфейс уровня лучших мобильных ассистентов**.

> Статус: идёт редизайн интерфейса. Технический аудит и исправления завершены —
> см. [отчёт](docs/SECURITY_FIXES_REPORT.ru.md).

## Чем DSH отличается

- **Безопасность по умолчанию.**
  - Нативные плагины загружаются только после вашего явного согласия: пакет и
    сертификат запоминаются, подмена подписи блокируется.
  - Токены зашифрованы ключом Android Keystore.
  - Удалённый Host — только по HTTPS с проверкой отпечатка.
  - Агенту по умолчанию закрыт буфер обмена.
  - Сборка проверяет SHA-256 каждой зависимости, релиз собирается с R8.
- **Надёжность.**
  - Обновление окружения атомарное: при сбое или выключении телефона откатывается.
  - Ответ агента переподключается после смены сети.
  - Состояние сохраняется при повороте экрана.
  - Приложение работает на Android 8 и новее.
- **Бережёт батарею.** Авто-сон Host при простое, фоновая работа только пока идёт задача,
  никаких опросов в фоне.
- **Приватность файлов.** Можно не давать доступ ко всем файлам — тогда рабочая папка
  живёт внутри приложения.
- **Русский язык** интерфейса и всех сообщений; также английский и китайский.

## Возможности

| | |
|---|---|
| Агент | Полноценные сессии DeepSeek Harness, потоковые ответы, инструменты, одобрение опасных действий |
| Рабочая папка | Файлы проекта на телефоне, импорт, предпросмотр, вложения в чат |
| Терминал | Команды в Linux-окружении (Debian + proot) рядом с агентом |
| Модели | DeepSeek и другие провайдеры по API-ключу |
| Плагины | Плагины Host и нативные плагины с интерфейсом на Compose |
| Несколько Host | Локальный Host на телефоне и удалённый Host по защищённому сопряжению |

## Сборка

Нужны JDK 21 и Android SDK 35.

```bash
./gradlew test                  # тесты
./gradlew :app:assembleDebug    # debug-сборка
./gradlew :app:assembleRelease  # релиз (R8; нужен keystore.properties)
```

При обновлении зависимостей перегенерируйте контрольные суммы:

```bash
./gradlew --write-verification-metadata sha256 test :app:assembleDebug :app:assembleRelease
```

## Структура

```
app/       приложение: навигация, экраны верхнего уровня
core/      модели, протокол, хранилище, дизайн-система
feature/   чат, сессии, файлы, настройки, среда выполнения
plugin/    хост нативных плагинов, Web-острова
runtime/   жизненный цикл локального Host, мост к устройству
docs/      отчёты и планы
```

## Происхождение

DSH основан на [deepseek-harness-mobile](https://github.com/EricFL1998/deepseek-harness-mobile)
(версия app-v1.0.6) и работает с [DeepSeek Harness](https://github.com/deepseek-ai/dsh).
Исходный проект не публикует файл лицензии — перед распространением сборок уточните
условия использования у его автора.
